DigitalRebel Studio - Installation

There is no installer. The zip file contains everything: the programs, the help pages, the examples and the settings. .NET does not need to be installed.

1. Extract the zip file

Extract the zip file (Windows: right-click > Extract All; Linux: archive manager or unzip). That is the whole installation. Do not take single files out of the extracted folder:

ItemWhat it is
drDesign-...The Designer, where you build projects.
drRunner-...The Runner, which only runs finished projects.
Help\The help pages and this page. The programs look for them in the Help folder next to the program file.
Examples\Example projects.
config.jsonSettings.
LICENSE.txt, THIRD-PARTY-NOTICES.txtLicense information.

2. Start the program for your system

The file name ends with a code for the operating system and processor:

CodeSystemFiles
X64Windows, Intel/AMD 64-bitdrDesign-X64.exe, drRunner-X64.exe
A64Windows, ARM 64-bitdrDesign-A64.exe, drRunner-A64.exe
LX64Linux, Intel/AMD 64-bitdrDesign-LX64, drRunner-LX64
LA64Linux, ARM 64-bit (for example Raspberry Pi)drDesign-LA64, drRunner-LA64
-AndroiddrRunner-A64.apk

If you are not sure on Windows, open Settings > System > About and read "System type".

Windows

Double-click the .exe file for your system. Nothing else is needed.

Linux

Give the file run permission once, then start it from a terminal in the extracted folder:

chmod 755 drDesign-LX64
./drDesign-LX64

The permission can also be set in the file manager: right-click the file > Properties > Permissions > "Allow executing file as program".

Double-click: many Linux file managers do not start a plain program file when you double-click it, even with run permission (you may get "Can't open the file ... application/x-executable"). The program itself is fine. Use the terminal command above, or right-click the file and choose Run as a Program (the wording differs between file managers).

A graphical desktop session (X11 or Wayland) is required. On very small or minimal systems, if the program does not start because a library is missing, install:

sudo apt install libx11-6 libice6 libsm6 fontconfig libfreetype6

Android (drRunner)

Transfer drRunner-A64.apk to the device (USB cable, cloud drive or download) and open it there. If Android asks, allow installing apps from this source (Settings > Apps > Special access > Install unknown apps; the wording differs between devices). Then tap Install.

3. Project files

Designer: projects (.drs files) are opened and saved with the Open/Save dialogs. You can keep them anywhere.

Runner: put the .drs files in the same folder as the Runner program. On startup the Runner decides what to load in this order:

  1. A file named autorun.drs next to the program - it is loaded directly.
  2. Otherwise the file named in config.json under "Project".
  3. Otherwise all .drs files are listed, and after 20 seconds the first one is opened.

4. Updating and removing

  • Update: extract the new zip file into the same folder and replace the files. If you changed settings, keep a copy of your config.json first, because the zip contains its own.
  • Remove: delete the extracted folder.

Zip dosyasını çıkarın (Windows: sağ tık > Tümünü ayıkla; Linux: arşiv yöneticisi ya da unzip). Kurulum bundan ibarettir. Çıkan klasörden tek tek dosya almayın:

Examples\Örnek projeler.

LICENSE.txt, THIRD-PARTY-NOTICES.txtLisans bilgileri.

2. Sisteminize uygun programı başlatın

Dosya adının sonundaki kod işletim sistemini ve işlemciyi gösterir:

KodSistemDosyalar
X64Windows, Intel/AMD 64 bitdrDesign-X64.exe, drRunner-X64.exe

Windows'ta emin değilseniz Ayarlar > Sistem > Hakkında bölümündeki "Sistem türü" satırına bakın.

Windows

Sisteminize uyan .exe dosyasına çift tıklayın. Başka bir şey gerekmez.

Linux

Dosyaya bir kez çalıştırma izni verin, sonra çıkardığınız klasörde bir terminalden başlatın:

İzin dosya yöneticisinden de verilebilir: dosyaya sağ tık > Özellikler > İzinler > "Dosyayı program olarak çalıştırmaya izin ver" (İngilizce: "Allow executing file as program").

Çift tıklama: birçok Linux dosya yöneticisi, çalıştırma izni olsa bile düz bir program dosyasına çift tıklanınca onu başlatmaz ("Dosya açılamıyor ... application/x-executable" gibi bir ileti çıkabilir). Program bozuk değildir. Yukarıdaki terminal komutunu kullanın ya da dosyaya sağ tıklayıp Run as a Program (Program olarak çalıştır) seçeneğini seçin (adı dosya yöneticisine göre değişir).

Grafik masaüstü oturumu (X11 veya Wayland) gerekir. Çok küçük ya da asgari sistemlerde bir kitaplık eksik olduğu için program başlamazsa şunu kurun:

sudo apt install libx11-6 libice6 libsm6 fontconfig libfreetype6

Android (drRunner)

drRunner-A64.apk dosyasını cihaza aktarın (USB kablo, bulut sürücü ya da indirme) ve orada açın. Android sorarsa bu kaynaktan uygulama kurulmasına izin verin (Ayarlar > Uygulamalar > Özel erişim > Bilinmeyen uygulamaları yükle; adı cihaza göre değişir). Sonra Yükle'ye dokunun.

3. Proje dosyaları

Tasarımcı: projeler (.drs dosyaları) Aç/Kaydet diyaloglarıyla açılır ve kaydedilir. İstediğiniz yerde tutabilirsiniz.

Runner: .drs dosyalarını Runner programıyla aynı klasöre koyun. Başlangıçta Runner neyi yükleyeceğine şu sırayla karar verir:

  1. Program dosyasının yanındaki autorun.drs adlı dosya - doğrudan yüklenir.
  2. Yoksa config.json içinde "Project" altında adı yazılı dosya.
  3. O da yoksa tüm .drs dosyaları listelenir ve 20 saniye sonra ilki açılır.

4. Güncelleme ve kaldırma

  • Güncelleme: yeni zip dosyasını aynı klasöre çıkarıp dosyaları değiştirin. Ayarları değiştirdiyseniz önce config.json'un bir kopyasını alın, çünkü zip kendi config.json'unu getirir.
  • Kaldırma: çıkardığınız klasörü silin.

1. Разархивирайте zip файла

Разархивирайте zip файла (Windows: десен бутон > Extract All; Linux: архиватор или unzip). Това е цялото инсталиране. Не изваждайте отделни файлове от получената папка:

ЕлементКакво е
drDesign-...Дизайнерът, в който създавате проектите.
drRunner-...Runner, който само изпълнява готови проекти.
Help\Помощните страници и тази страница. Програмите ги търсят в папката Help до програмния файл.
Examples\Примерни проекти.
config.jsonНастройки.
LICENSE.txt, THIRD-PARTY-NOTICES.txtЛицензна информация.

2. Стартирайте програмата за вашата система

Краят на името на файла е код за операционната система и процесора:

КодСистемаФайлове
X64Windows, Intel/AMD 64-bitdrDesign-X64.exe, drRunner-X64.exe
A64Windows, ARM 64-bitdrDesign-A64.exe, drRunner-A64.exe
LX64Linux, Intel/AMD 64-bitdrDesign-LX64, drRunner-LX64
LA64Linux, ARM 64-bit (например Raspberry Pi)drDesign-LA64, drRunner-LA64
-AndroiddrRunner-A64.apk

Ако не сте сигурни в Windows, отворете Settings > System > About и прочетете "System type".

Windows

Щракнете двукратно върху .exe файла за вашата система. Нищо друго не е нужно.

Linux

Дайте на файла право за изпълнение веднъж, после го стартирайте от терминал в разархивираната папка:

chmod 755 drDesign-LX64
./drDesign-LX64

Правото може да се зададе и във файловия мениджър: десен бутон върху файла > Properties > Permissions > "Allow executing file as program" (Разреши изпълнението на файла като програма).

Двукратно щракване: много файлови мениджъри в Linux не стартират обикновен програмен файл при двукратно щракване, дори да има право за изпълнение (може да се появи "Can't open the file ... application/x-executable"). Самата програма е наред. Използвайте командата в терминала по-горе или щракнете с десния бутон върху файла и изберете Run as a Program (Стартирай като програма; името се различава между файловите мениджъри).

Нужна е графична работна среда (X11 или Wayland). На много малки или минимални системи, ако програмата не стартира, защото липсва библиотека, инсталирайте:

sudo apt install libx11-6 libice6 libsm6 fontconfig libfreetype6

Android (drRunner)

Прехвърлете drRunner-A64.apk на устройството (USB кабел, облачно хранилище или изтегляне) и го отворете там. Ако Android попита, разрешете инсталиране на приложения от този източник (Settings > Apps > Special access > Install unknown apps; наименованията се различават между устройствата). След това докоснете Install (Инсталирай).

3. Файлове на проектите

Дизайнер: проектите (.drs файлове) се отварят и записват с диалозите Open/Save. Можете да ги държите където искате.

Runner: сложете .drs файловете в същата папка като програмата Runner. При стартиране Runner решава какво да зареди в този ред:

  1. Файл с име autorun.drs до програмата - зарежда се директно.
  2. Иначе файлът, посочен в config.json под "Project".
  3. Иначе се показват всички .drs файлове и след 20 секунди се отваря първият.

4. Обновяване и премахване

  • Обновяване: разархивирайте новия zip файл в същата папка и заменете файловете. Ако сте променяли настройки, първо запазете копие на config.json, защото zip файлът съдържа свой.
  • Премахване: изтрийте разархивираната папка.

DigitalRebel Studio - Instalación

No hay instalador. El archivo zip contiene todo: los programas, las páginas de ayuda, los ejemplos y los ajustes. No hace falta tener .NET instalado.

1. Extraiga el archivo zip

Extraiga el archivo zip (Windows: clic derecho > Extraer todo; Linux: gestor de archivos comprimidos o unzip). Esa es toda la instalación. No saque archivos sueltos de la carpeta extraída:

ElementoQué es
drDesign-...El Diseñador, donde se crean los proyectos.
drRunner-...El Runner, que solo ejecuta proyectos terminados.
Help\Las páginas de ayuda y esta página. Los programas las buscan en la carpeta Help junto al archivo del programa.
Examples\Proyectos de ejemplo.
config.jsonAjustes.
LICENSE.txt, THIRD-PARTY-NOTICES.txtInformación de licencia.

2. Inicie el programa de su sistema

El final del nombre del archivo es un código del sistema operativo y del procesador:

CódigoSistemaArchivos
X64Windows, Intel/AMD de 64 bitsdrDesign-X64.exe, drRunner-X64.exe
A64Windows, ARM de 64 bitsdrDesign-A64.exe, drRunner-A64.exe
LX64Linux, Intel/AMD de 64 bitsdrDesign-LX64, drRunner-LX64
LA64Linux, ARM de 64 bits (por ejemplo Raspberry Pi)drDesign-LA64, drRunner-LA64
-AndroiddrRunner-A64.apk

Si no está seguro en Windows, abra Configuración > Sistema > Acerca de y lea "Tipo de sistema".

Windows

Haga doble clic en el archivo .exe de su sistema. No hace falta nada más.

Linux

Dele al archivo permiso de ejecución una sola vez y luego inícielo desde un terminal en la carpeta extraída:

chmod 755 drDesign-LX64
./drDesign-LX64

El permiso también se puede dar en el gestor de archivos: clic derecho en el archivo > Propiedades > Permisos > "Permitir ejecutar el archivo como un programa" (en inglés: "Allow executing file as program").

Doble clic: muchos gestores de archivos de Linux no inician un archivo de programa simple con doble clic, aunque tenga permiso de ejecución (puede aparecer "No se puede abrir el archivo ... application/x-executable"). El programa en sí está bien. Use el comando de terminal anterior o haga clic derecho en el archivo y elija Run as a Program (Ejecutar como programa; el nombre varía según el gestor de archivos).

Se necesita una sesión de escritorio gráfica (X11 o Wayland). En sistemas muy pequeños o mínimos, si el programa no inicia porque falta una biblioteca, instale:

sudo apt install libx11-6 libice6 libsm6 fontconfig libfreetype6

Android (drRunner)

Transfiera drRunner-A64.apk al dispositivo (cable USB, unidad en la nube o descarga) y ábralo allí. Si Android lo pide, permita instalar aplicaciones desde esta fuente (Ajustes > Aplicaciones > Acceso especial > Instalar apps desconocidas; los nombres varían según el dispositivo). Después toque Instalar.

3. Archivos de proyecto

Diseñador: los proyectos (archivos .drs) se abren y se guardan con los diálogos Abrir/Guardar. Puede guardarlos donde quiera.

Runner: coloque los archivos .drs en la misma carpeta que el programa Runner. Al iniciar, el Runner decide qué cargar en este orden:

  1. Un archivo llamado autorun.drs junto al programa - se carga directamente.
  2. Si no, el archivo indicado en config.json bajo "Project".
  3. Si no, se listan todos los archivos .drs y, tras 20 segundos, se abre el primero.

4. Actualizar y quitar

  • Actualizar: extraiga el nuevo archivo zip en la misma carpeta y sustituya los archivos. Si cambió ajustes, guarde antes una copia de config.json, porque el zip trae el suyo.
  • Quitar: elimine la carpeta extraída.
