Install

From the zip to a running panel

Download, unpack, start the Designer, save a project, start it in the Runner.

Windows

Unpack the zip and start drDesign-X64.exe (or drDesign-A64.exe on ARM). If SmartScreen asks, choose “More info”, then “Run anyway”: the file is not signed yet.

Linux

The files have no extension. Make them runnable once, then start them:

chmod +x drDesign-LX64 drRunner-LX64
./drDesign-LX64

Android

Copy drRunner-A64.apk to the device and open it. Android asks once to allow installs from this source. Only the Runner exists for Android; projects are designed on a desktop.

Free to use

The Runner and its licence limit

DRS is completely free, and it is a project that supports education. The Runner carries a licence limit for one reason only: to prevent commercial use. The time limit applies to every run, and it does not block tests and experiments. It is not a price tag: the licence key is free too, and nothing in it phones home.

What the limit does

On a device without a licence the project still starts and works. The frame of the scheme turns red, and the Runner closes by itself after one minute. A licensed device runs without the red frame and without the timer.

Everything works on the desktop

The limit is in the Runner only. You can design, run, test and watch a project in the Designer on a desktop as long as you like, with every component and every connection. A licence is needed only to leave a panel running on its own device.

On a phone or a tablet

One minute is enough to enter a few parameters and close: set a value, change an address, switch a mode, then leave. Open the project again whenever you need it; each start gives a new minute.

How to get a licence (free)

  1. Run the Runner on the device and start a project once. Without a licence it creates config.json by itself, in the folder of the Runner program (on Android: /storage/emulated/0/DRS), and writes the encrypted lock of that device into the field LicenseKey.
  2. Send that config.json to erol.micset@gmail.com.
  3. You get a key back. Write it into config.json, in the field License, and start the Runner again.

The key belongs to the hardware, not to the operating system, so reinstalling the system on the same machine keeps it valid. A phone that is reset to factory settings gets a new identity and needs a new key.

What stays the same

No account, no telemetry, nothing that phones home. The panel you build today opens in the same program next year: a folder, an executable and your project file.
