Build an ESP32 control panel in ten minutes

Draw a panel with a switch, a lamp and a dial, let DRS write the Arduino sketch, upload it, and control the board from your screen. It works the same way for an Arduino, a Raspberry Pi Pico or any board with a serial port, and nothing costs money.

Before you start

What you need

  • DRS for Windows or Linux, from the download page.
  • An ESP32 board with a USB cable, and the Arduino IDE. No board? Use drQEmu and skip the cable.
  • An LED on a pin is optional: most ESP32 boards have one on pin 2.

Steps

From an empty project to a working panel

1. Add a serial port

Create a new project and add a serial port component. Set the port your board uses and the speed 115200.

2. Add an LZ client

Add an LZ client and set its Transport to the serial port. This is the part that speaks to the board.

3. Add three tags

Under the client add three tags named Led, Button and Analog. The name is exactly what goes on the line.

4. Tell each tag its pin

Because the sketch is generated, each tag also says how the board uses it. Led: Output, Digital, pin 2. Button: Input, Digital, pin 0. Analog: Input, Analog, pin 34. A tag with no pin simply keeps a value, which is useful for set points.

5. Generate the sketch

Open the client's menu and choose Generate Arduino Server. View the code or save it as an .ino file. Use Float as the value type if you need decimals.

6. Upload it

Open the file in the Arduino IDE, choose your ESP32 board and upload. The sketch answers the panel; the loop is yours for everything else.

7. Draw the panel

Add a switch, an LED and a dial, and link each to the value of a tag. Run the project.

8. Watch it work

Flip the switch and the board's LED follows. Press the button on the board and the lamp lights. Turn the analog input and the dial moves.

Try before you build

Test the panel with no board

Every tag can take its value from a random generator instead of a device, so you can draw and test the whole panel first. When it looks right, switch the tags back to the board.

The finished panel and its sketch are ready to download: the panel as LZ-Serial-Panel.drs and the sketch as LZClient1.ino. Run the sketch in drQEmu and the same panel talks to an emulated ESP32.

Next

Where to go from here

Other boards

The protocol is plain text, so a PIC, an AVR or a Pico needs only the same few lines. See how it works.

Wireless

Generate the sketch for Ethernet, WiFi or Bluetooth instead of the serial port. The panel stays the same.

Several boards on one line

Set the client to Addressed and give each tag a device address, so boards on one RS485 line share the connection.

Keep the data

Log the values, draw trend charts, print a report or pass the data on over MQTT and REST. See the gateway.
