drQEmu

An ESP32 on your screen

drQEmu runs the program you compiled for an ESP32 on your PC. The pins, the I2C and SPI buses and the chips on them are drawn in a browser page: press a button, turn a knob, see the display. It is a separate program from DRS, with its own download.

Use

From a sketch to a running board

Compile the sketch, start drQEmu, load the image, watch and drive the board in the browser.

The image

Compile your sketch the way you always do and keep the merged image (the .merged.bin file). That file is what drQEmu runs: the same bytes you would write to a board.

Windows and Linux

Start drQEmuESP32.exe, or on Linux make drQEmuESP32 runnable once with chmod +x and start it. The page opens in your browser; the help page in the zip explains every part of it.

Real boards

drFlasher writes an image to a connected ESP32 board over its serial port. It is a separate file: you do not need it to use the emulator.
