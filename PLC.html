Olympus PLC

A programmable controller you can build on

Olympus is a developer PLC built around an ESP32. It has been tested. It talks over serial, RS485, Bluetooth and WiFi, keeps its data on a memory card, and takes plug-in input and output modules, so you can use it as it is or build your own controller on the same idea.

With DRS

How a panel talks to it

A DRS panel reads and writes the controller through the LZ protocol: one tag in each request, one answer back. DRS is the studio that draws the panel.

What it has

Features

Communication

USB serial, RS232 or TTL, RS485, Bluetooth and WiFi.

Storage and interface

A Micro SD card for a SQLite database, an OLED display, a keypad, and a real-time clock with RAM.

Inputs and outputs

Ten flexible multifunction points: TTL, analog input and output, NPN or PNP digital outputs and relay outputs. Each point can be set as an input or an output.

Also on the board

An infrared receiver, I2C, a 0 to 10 V analog output and a reset button.

Modules

Fixed or plug-and-play digital and analog modules through sockets; DIP and SMD assembly and custom soldering are possible, so you can build your own controller.

Programming

It uploads from the Arduino IDE over USB automatically, without pressing any button.
